# GrowOS（仮称）要件定義 v0.1

## ■ プロジェクト概要

目的は「水耕栽培システムを作ること」ではなく、

**誰でも植物を育てられるIoTプラットフォーム（GrowOS）を開発すること。**

将来的には家庭向けだけでなく、飲食店・ホテル・学校・工場・自治体・鉄道会社（高架下活用）などへ展開する。

最終目標は

「空いているスペースを収益化するソリューション」

として販売する。

---

# コンセプト

・空いているスペースを有効活用
・モジュールをレゴのように増設可能
・ブラウザからどこでも監視
・異常を自動検知
・可能なら自動復旧
・専門知識不要で運用できる

# 開発方針

・まずは動くものを最速で作る（MVP）
・設計は将来の企業利用を前提とする
・ESP32は制御・通信のみ担当
・判断ロジックはBackendへ集約
・後からセンサー追加が容易な設計にする
・モジュール構造で拡張可能にする
・OTAアップデートを考慮した設計にする
